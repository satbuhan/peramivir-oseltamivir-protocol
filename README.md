# Antiviral Selection in Primary Influenza Pneumonia: IV Peramivir vs Oral Oseltamivir

An interactive, referenced walkthrough of the decision algorithm for choosing between
intravenous peramivir and oral oseltamivir in suspected or confirmed primary influenza
pneumonia: starting a neuraminidase inhibitor immediately without waiting for test results,
the enteral-route-reliability check that decides between the two agents, supportive and
adjunctive care, the 48-to-72-hour reassessment, and what to do — including testing for the
H275Y resistance substitution — when a patient is not improving. Every box in the diagram
can be selected to reveal, in one place: what the step means, why the algorithm calls for
it, and the sources behind it.

**Live site:** https://satbuhan.github.io/peramivir-oseltamivir-protocol/

**Authors:** Dr. Özgür Karcıoğlu & Dr. Satuk Buğra Han Bozatlı

## Why this exists

The figure this page presents is not a revision of this atlas's existing
[`influenza-antiviral-protocol`](https://github.com/satbuhan/influenza-antiviral-protocol) —
that tool covers a different decision (baloxavir marboxil vs oseltamivir, chosen by drug
class and risk stratification). This tool is a separate, sibling algorithm built from its own
systematic review: given that a patient already needs a neuraminidase inhibitor for
suspected or confirmed primary influenza pneumonia, which route-equivalent agent — oral
oseltamivir or intravenous peramivir — should be started, decided by whether the enteral
route can actually be relied on. The review's own bottom line (carried through to this page's
closing evidence banner) is that the two drugs are clinically equivalent: peramivir's IV
route is a practical advantage when oral/enteral delivery is unreliable, not a sign that it
works better.

## Status

This is a working version, built to be tested on both desktop and mobile.

- **Source workflow:** built from a dedicated source-extraction document (the manuscript's
  figure box text transcribed field-by-field, its own "Consolidated Checklist of
  Guideline-Sourced or Unstated Details" flagging eight places where figure wording is not
  from the review's own synthesis, and its full 103-entry bibliography with DOIs).
- **Citation verification — independently re-verified, no exception used:** every reference
  on this page was individually cross-checked against a locatable primary source (the
  trial/cohort report itself, a guideline document, or an indexing record confirming
  title/author/journal/year/DOI) rather than accepted from the source manuscript's own
  reference list. Three of the manuscript's own cited sources — its refs on a 2024 WHO
  guideline update, on antiviral management of critically ill influenza patients, and on
  pneumonia burden in a Spanish H1N1 cohort — could **not** be independently confirmed after
  repeated, differently-worded searches, and are deliberately **not** reproduced here; the
  clinical points they backed are instead covered by other, verified references already in
  this page's bibliography. This is the opposite policy from the explicit author-granted
  exception used in `dapagliflozin-overdose-protocol` and several later tools — this tool's
  bibliography is independently sourced from the ground up.
- **The one place the figure and the manuscript's own text meaningfully diverge:** the
  "search for coinfection or complications; test for NA resistance (H275Y)" box's sub-text
  says to "consider IV zanamivir" for documented H275Y cross-resistance. The review's own
  text never recommends this — it says IV zanamivir was **not** superior to oral oseltamivir
  in a large phase 3 trial and is **not widely available**. The figure's box text is
  transcribed exactly as authored; this discrepancy is surfaced as a clinical caution on that
  node rather than silently resolved either way.

## Disclaimer

This is an academic / educational reference tool, not a substitute for institutional protocol
or bedside clinical judgement. This algorithm applies to patients with suspected or confirmed
primary influenza pneumonia being considered for neuraminidase-inhibitor therapy; it is not a
general influenza-management guide and does not replace local antimicrobial stewardship or
infection-control guidance.

## How it's built

Plain HTML/CSS/JS, no build step and no framework — a single static site that GitHub Pages
can serve directly.

```
index.html          page structure — masthead, the diagram (entry, start-NAI-immediately,
                     the enteral-route-reliability decision and its two branches, supportive
                     care, the 48-72h reassessment decision and its two branches, the closing
                     evidence-summary banner), readout panel, references, abbreviation
                     legend, footer
assets/style.css     design (the "paper" masthead/references, the diagram grid, the dashed
                     muted "note" tone used for the evidence-summary banner)
assets/content.js    ← single source of truth for every node's text and reference list. Edit
                     this file to change what the page says.
assets/app.js        rendering + interaction (builds the diagram and its connector lines from
                     content.js; handles the click-to-expand panel on desktop and the bottom
                     sheet on mobile)
```

### Running it locally

No install needed:

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

### Editing content

Open `assets/content.js`. Each entry in `NODES` is one box from the diagram (`meaning`,
`rationale`, optional `dose`/`cautions`, and `refs` pointing at numbered entries in
`REFERENCES`). Add or edit a reference in `REFERENCES` and point to it by `id` from any node.
Never change a node's `label` or `sub` text without the author team's sign-off — those fields
are the algorithm itself, transcribed verbatim from the authors' own figure.
